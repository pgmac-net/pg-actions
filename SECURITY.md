# Security Policy

## Supported versions

Only the `main` branch is supported. Consumers should reference these reusable
workflows by commit SHA or track `main`.

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's
[private vulnerability reporting](https://github.com/pgmac-net/pg-actions/security/advisories/new).
Do not open a public issue for security problems.

You can expect an initial response within 7 days. This is a single-maintainer
project, so fix timelines are best effort.
